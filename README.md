## 📌 Sobre o projeto

Este projeto foi desenvolvido como atividade da disciplina de Desenvolvimento de Sistemas.

O programa tem como objetivo classificar o perfil de consumo de água de um imóvel e apresentar mensagens educativas de acordo com o tipo de imóvel e o consumo mensal informado pelo usuário.

## ⚙️ Funcionalidades

O sistema solicita:

- 🏠 Tipo de imóvel: comercial, casa ou apartamento;
- 💧 Consumo mensal de água em metros cúbicos (m³).

Após receber as informações, o programa classifica o consumo como:

- 🏢 Tarifa comercial;
- 🌱 Consumo econômico;
- ✅ Consumo moderado;
- ⚠️ Consumo excessivo.

## ▶️ Como executar

1. Certifique-se de ter o Python 3.10 ou superior instalado.
2. Baixe ou clone este repositório.
3. Acesse a pasta `consumo-agua`.
4. Execute o arquivo:

```bash
python app.py
```

🎯 Objetivo

O projeto busca aplicar estruturas condicionais em Python para resolver um problema relacionado ao consumo consciente de água, utilizando regras diferentes de acordo com o perfil do imóvel.
